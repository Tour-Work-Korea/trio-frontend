# 공유 링크 공통 미리보기

2026-11-08: 사용자가 허용한 간단한 공통 미리보기 방식으로 적용했다.

- 게하와 파티 공유 링크 모두 기존 게딱지 앱 로고와 기존 공통 제목/설명을 사용한다.
- 이미지: `apps/web/public/share/ddakji-preview-v1.png`. 기존 iOS 1024px 앱 아이콘을 그대로 복사했고 원본을 수정하지 않았다.
- `apps/web/index.html`의 최초 HTML에 Open Graph 이미지와 Twitter 이미지를 제공하므로 JavaScript 실행에 의존하지 않는다.
- 모든 상세 URL을 홈페이지로 식별하던 고정 `og:url`은 제거했다. 공유 주소 및 앱/웹 상세 이동 코드는 바꾸지 않았다.
- 기존 Vite public 파일 복사 및 웹 배포 경로를 사용한다. 별도 서버나 API는 추가하지 않았다.
- 숙소·파티별 사진/이름은 이번 범위에 포함하지 않는다. 정적 배포에서 이를 지원하려면 동적 HTML 응답 또는 상세별 HTML 사전 생성과 데이터 갱신 정책이 필요하다.

적용을 위해 웹 배포가 필요하다. 실제 카카오톡/인스타 DM 미리보기는 새로 테스트하지 않았고 표시 형태를 보장하지 않는다. 플랫폼 캐시 때문에 예전 정보가 남을 수 있다. 카카오에서는 OG 캐시 초기화 도구로 갱신할 수 있다.

새 고정 사용자 문구/번역 키는 없다. 기존 한국어 공통 제목/설명을 그대로 재사용한다. 서버·사용자 콘텐츠는 읽거나 변경하지 않았다.

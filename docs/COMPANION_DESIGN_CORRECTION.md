# 커뮤니티 동행 목록·상세 디자인 수정

2026-10-20에 다시 전달받은 두 시안을 기준으로 수정했다.

## 반영한 화면

- 동행 탭: 기존 커뮤니티 게시글과 같은 작성자/시간/제목/소개 배치. 카드 테두리와 추가한 모집 상태·지역 필터를 제거했다.
- 일정과 장소는 본문 아래에 회색 달력/위치 SVG와 함께 표시한다. 하루 일정은 날짜를 한 번만 표시하고 장소가 없으면 지역만 표시한다.
- 마감된 글은 제목 옆 작은 회색 배지와 회색 본문으로 표시한다. 스탭 바로 오른쪽의 동행 탭 순서는 유지한다.
- 상세: 기존 CommunityDetail 화면을 재사용한다. 본문 아래에 장소/날짜/작성자 포함 총인원을 담은 동행 정보와 채팅 버튼을 넣는다.
- 좋아요/댓글 수, 댓글·답글, 기존 광고 노출 분기, 댓글 입력창을 유지한다. 따로 만들었던 상세 상단 상태 배지, 안내 카드, 화면 하단 고정 채팅 버튼은 제거했다.
- 이미 연결된 작성자 모집 관리/확정자 단체방 이동 권한은 본문 아래 버튼에서 유지한다.

## 데이터 연결 및 API 확인

최신 https://docs.ddakji.kr/v3/api-docs.yaml 을 다시 받아 공개 동행 목록/상세와 공개 커뮤니티 게시글 상세 GET 계약을 확인했다. Summary에 없는 소개·작성자·장소는 현재 페이지에 해당하는 동행 상세/공개 게시글 상세로 보충한다. OPEN/CLOSED 페이지를 함께 읽어 마감 글도 같은 목록에 표시하며, 상세 조회 작업은 최대 4개 게시글씩 수행한다. 정렬은 현재 불러온 게시글의 작성 시각에 적용한다. 전체 목록의 서버 기준 작성순 정렬은 동행 API의 정렬 옵션 지원이 필요하다.

## 검증

- 한국어 375px 목록/상세, 영어 320px 목록/상세 시각 확인.
- 테스트 데이터로 작성자/본문/일정/장소/마감/총인원 및 기존 댓글·답글·입력창 표시 확인. 서버에 글이나 댓글을 생성하지 않았다.
- 동행 회귀 및 공개 목록 데이터 보충 테스트 18개 통과.
- 한·영 번역 키 일치 검사 및 수정 파일 ESLint 오류 0건.
- 웹 빌드 확인. 임시 테스트 화면 소스는 검증 후 제거한다.

## 추가한 고정 문구 전체

| 키 | 한국어 | English |
| --- | --- | --- |
| `companion.totalLabel` | 총 인원 | Total people |
| `companion.detailTotal` | {{value}}명 (작성자 포함) | {{value}} people (including organizer) |
| `companion.detailTotal_one` | {{value}}명 (작성자 포함) | {{value}} person (including organizer) |
| `companion.detailTotal_other` | {{value}}명 (작성자 포함) | {{value}} people (including organizer) |

나머지 고정 문구는 기존 한·영 키를 재사용했다. 제목, 소개, 닉네임, 장소명·주소, 댓글·답글은 서버/사용자 원문을 유지한다. 주소에는 trimJejuPrefix를 적용한다. 아이콘은 기존 calendar_gray.svg, map_pin_fill_gray.svg, people_gray.svg 및 기존 커뮤니티 상세 아이콘을 재사용했다.

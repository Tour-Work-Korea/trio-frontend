# 동행 글쓰기 디자인 수정

- 사진 기준 2단계(일정과 모집 / 소개) 유지, 글쓰기 제목과 동행 분류 표시.
- 둥근 입력창, 지역 선택 드롭다운, 주황색 장소 아이콘, 나란한 날짜 입력, 테두리 인원 조절 버튼, 사진 추가 칸 적용.
- 당일 기간 선택 가능. 장소·사진 선택 사항, 소개 10~1,000자, 사진 최대 5장 기존 처리 유지.
- 기존 SVG 재사용. API 요청 구조 변경 없음.
- 사용자 요청에 따라 테스트·빌드·번역 검증·브라우저 확인 미실행. 요청 시에만 테스트하도록 AGENTS.md에 기록.

## 새 고정 문구

| 키 | 한국어 | 영어 |
|---|---|---|
| companion.writeHeader | 글쓰기 | Write a post |
| companion.regionSelect | 지역을 선택해 주세요 | Select a region |
| companion.descriptionHelp | 함께할 활동을 적어 주세요. · 10~1,000자 | Describe your activities together. · 10–1,000 characters |
| companion.photosHelp | 사진은 최대 5장까지 올릴 수 있어요. | You can add up to 5 photos. |

사용자가 작성하는 제목·소개·장소는 번역하지 않고 입력 그대로 유지합니다.

## 카테고리·드롭다운·필수값 재수정

- 기존 커뮤니티 글쓰기의 카테고리 메뉴 스타일 재사용. 다른 카테고리를 고르면 해당 카테고리가 선택된 일반 글쓰기로 전환.
- 지역 목록은 모달 대신 입력칸 바로 아래에 펼쳐지는 드롭다운으로 수정.
- 한국어 날짜 표시는 `2026. 10. 03` 형식. 영어는 기존 로케일 날짜 포맷 유지.
- 입력란은 이 화면 전용 스타일로 테두리·48px 최소 높이·둥근 모서리·패딩 적용. 활동 선택 칩도 시안의 간격과 크기에 맞춰 로컬 적용.
- 1단계 필수값과 날짜 유효성 검사를 통과하기 전에는 다음 버튼 비활성화. 소개 10~1,000자 조건까지 만족해야 등록/저장 활성화.
- 최신 API 문서에서 공개 커뮤니티 카테고리 조회와 STAFF 작성 대상 제외 규칙 확인. 기존 호출 재사용.
- 새 고정 문구나 번역 키 없음. API 카테고리 이름과 사용자 입력은 번역하지 않음.
- 사용자 지시에 따라 테스트·빌드·브라우저 확인은 실행하지 않음.
